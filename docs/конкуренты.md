## 2. Выгрузка цен и остатков в файл

**Вендор:** ООО «Эффективные решения для интернет-бизнеса»

| Параметр | Значение |
|---|---|
| Установки | 200+ |
| Пробный период | Бесплатно 7 дней |
| Стоимость | 1000 ₽ за месяц |

**Описание:**

«Выгрузка цен и остатков в файл» — приложение для гибкой и автоматической выгрузки информации о товарах из МойСклад в разные форматы файлов и их отправки в различные сервисы.

Поддерживаются товары, модификации и комплекты.

> Настройка занимает несколько минут и не требует программирования или специальных знаний.  
> Если что-то не получится — разработчик поможет.

### Что можно выгрузить

- ID группы
- UUID
- Артикул
- Архивирован: да / нет
- Валюта
- Вес
- Внешний ID
- Время обновления
- Высота
- Глубина
- Группа — категория товара
- Дополнительные поля  
  При клике на поле появляется список с выбором: выгрузить все или конкретные поля. Если нужно изменить выбранные поля, можно снова кликнуть по полю и изменить выбор.
- Единица измерения
- Изображения  
  Выгружается постоянная ссылка на изображения. Если изображений несколько, ссылки перечисляются через запятую.
- Код
- Количество вариантов
- Количество дней на складе
- Маркировка / тип продукции
- Наименование
- Объем
- Описание
- Остатки  
  Можно выгружать любые остатки любого склада либо сумму остатков в зависимости от настроек. Доступные варианты:
  - Доступно
  - Ожидание
  - Остаток
  - Резерв
- Цена  
  Можно выгрузить любой тип цен. Если выбрано несколько цен, каждая выгружается в отдельную колонку.
- Цена закупочная
- Цена минимальная
- Ширина
- Штрихкод

> Список перечисленных полей может отличаться, так как добавляются новые.  
> Актуальный список доступных полей можно увидеть внутри приложения.

Также можно выгрузить:

- модификации;
- комплекты.

### Дополнительные поля для Узбекистана

Для Узбекистана дополнительно выгружаются:

- ТАСНИФ Код
- ТАСНИФ Код упаковки
- ТАСНИФ Штрихкод

### Возможности приложения

- Выгрузка товаров в форматы:
  - Excel (XLSX)
  - CSV
  - XML
  - JSON
  - YML
- Выбор организации, складов, типов цен
- Настройка состава и порядка полей выгрузки
- Фильтрация по дополнительным полям
- Фильтрация товаров по:
  - цене;
  - количеству;
  - категории;
  - дополнительным полям;
  - другим параметрам
- Автоматический запуск экспорта по расписанию
- Постоянная прямая ссылка на файл выгрузки

## 3. Выгрузка заказов

**Вендор:** ООО «Эффективные решения для интернет-бизнеса»

| Параметр | Значение |
|---|---|
| Установки | 50+ |
| Пробный период | Бесплатно 7 дней |
| Стоимость | 1000 ₽ за месяц |

**Описание:**

Универсальный экспорт заказов для МоегоСклада.

Расширение предназначено для автоматизации выгрузки заказов покупателей из МоегоСклада во внешние системы, файлы и каналы связи.

Приложение позволяет гибко настраивать:

- состав данных;
- расписание;
- способы доставки.

### Основные возможности

#### Поддерживаемые форматы

- **Excel (XLSX)**  
  Профессиональные таблицы с автоподбором ширины колонок и группировкой.
- **CSV**  
  Универсальный текстовый формат для импорта в другие системы.
- **JSON**  
  Для интеграции с веб-сервисами.
- **XML**  
  Для интеграции с веб-сервисами.
- **HTML**  
  Интерактивные отчеты с поиском, пагинацией и отображением изображений товаров.

#### Каналы доставки

- **Email (SMTP)**  
  Автоматическая отправка файлов на одну или несколько почт. Поддерживается SSL/TLS.
- **Google Sheets**  
  Прямая выгрузка данных в ваши таблицы Google в реальном времени.
- **Telegram**  
  Получение файлов и уведомлений через Telegram-бота.
- **FTP/SFTP**  
  Загрузка отчетов на удаленные серверы.
- **Webhooks**  
  Отправка данных по протоколу POST на любой URL.
- **Базы данных**  
  Запись данных напрямую в MySQL или SQLite.

#### Гибкая фильтрация заказов

- По организациям и складам
- По статусам заказов  
  Можно выбрать один или несколько статусов.
- По периоду:
  - сегодня;
  - вчера;
  - текущая неделя;
  - текущий месяц;
  - произвольный диапазон дат
- По сумме заказа:
  - минимальная сумма;
  - максимальная сумма

#### Настройка данных

- Выбор из 30+ стандартных полей:
  - номер;
  - дата;
  - сумма;
  - покупатель;
  - адрес;
  - артикул;
  - штрихкод;
  - скидки;
  - другое
- Полная поддержка дополнительных полей / характеристик заказов
- Опция «Один заказ = одна строка» для создания кратких сводных отчетов
- Специальные поля для региона Узбекистан:
  - ИКПУ;
  - коды упаковок;
  - маркировка

#### Автоматизация по расписанию

- Ежедневно в указанное время
- Интервальный запуск каждые N часов
- «Умный» режим  
  Автоподбор интервала в зависимости от объема данных

### Преимущества

- Простая установка и интуитивно понятный интерфейс управления
- Стабильная работа с большими объемами данных
- Возможность создания множества независимых конфигураций / профилей экспорта
- Контроль статуса выполнения задач в реальном времени

### Инструкция по началу работы

1. Установите расширение в вашем аккаунте МойСклад.
2. Откройте приложение и создайте новую конфигурацию экспорта.
3. Выберите нужные фильтры, поля для выгрузки и способ доставки.
4. Проверьте настройки с помощью кнопки «Тест» и активируйте расписание, если требуется автоматизация.

Если недостаточно функционала анализа в Google Таблицах, можно задействовать расширенные возможности Google Data Studio.

### Что выгружается

#### В момент создания или обновления

Выгружаются следующие сущности:

- Заказы покупателей, включая позиции
- Продажи, включая отгрузки и розничные продажи, включая позиции
- Платежи, включая входящие и исходящие платежи, приходные и кассовые ордера
- Заказы поставщикам, включая позиции
- Приемки, включая позиции
- Возвраты, включая позиции
- Списания и оприходования, включая позиции
- Полученные отчеты комиссионеров, включая позиции

#### На периодической основе

На данный момент — один раз в сутки:

- Ассортимент, включая остатки и резервы по складам
- Контрагент, включая показатели контрагента, если подключена опция МойСклад CRM

### Возможные применения приложения

- Анализ движения денежных средств / отчет ДДС
- План/факт продаж
