2) Выгрузка цен и остатков в файл
ООО «Эффективные решения для интернет-бизнеса»
200+ установок
Бесплатно 7 дней, далее — 1000₽ за месяц

Выгрузка цен и остатков в файл - это приложение для гибкой и автоматической выгрузки информации о товарах (в том числе модификации и комплекты) из МойСклад в разные форматы файлов и их отправки в различные сервисы.

Настройка занимает несколько минут и не требует программирования или специальных знаний. А если что то не получится - мы поможем.

!Ниже приведен список полей, а так же функционал и куда можно выгрузить данные.

Что можно выгрузить:
- ID Группы
- UUID
- Артикул
- Архивирован (да, нет)
- Валюта
- Вес
- Внешний ID
- Время обновления
- Высота
- Глубина
- Группа - категория товара
- Дополнительные поля - при клике на поле появляется список с выбором, что выгрузить, все или конкретные. Если нужно изменить выбранные поля - снова кликаем на него и изменяем.
- Единица измерения
- Изображения - выгружается постоянная ссылка на Изображения. Если их несколько - ссылки перечисляются через запятую.
- Код
- Количество вариантов
- Количество дней на складе
- Маркировка (Тип продукции)
- Наименование
- Объем
- Описание
- Остатки - выгружаются любые остатки любого склада, либо сумма остатков, в зависимости от настроек. Можно выгрузить Доступно, Ожидание, Остаток, Резерв.
- Цена - можно выгрузить любой тип цен. Если выбрано несколько цен, то каждая выгружается в отдельную колонку.
- Цена закупочная
- Цена минимальная
- Ширина
- Штрихкод
Список перечисленных полей может отличаться, т.к. добавляются новые. Актуальный список доступных полей можно увидеть внутри приложения.

Можно выгрузить модификации и комплекты.

Для Узбекистана дополнительно выгружаются:
- ТАСНИФ Код
- ТАСНИФ Код упаковки
- ТАСНИФ Штрихкод


Возможности приложения:

- выгрузка товаров в форматы Excel (XLSX), CSV, XML, JSON, YML;
- выбор организации, складов, типов цен;
- настройка состава и порядка полей выгрузки;
- фильтрация по дополнительным полям;
- фильтрация товаров по цене, количеству, категории, доп. полям и др.;
- автоматический запуск экспорта по расписанию;
- постоянная прямая ссылка на файл выгрузки;
- отправка файла в Google-таблицы, на почту, Телеграм и др. сервисы.


Куда можно отправить (выгрузить) файл:

- файл всегда доступен по секретной ссылке
- рассылка на почту
- загрузка в Google Таблицы
- отправка в Telegram
- загрузка на FTP / SFTP
- вызов Webhook после завершения экспорта
- загрузка в вашу базу данных (MySQL / MariaDB, PostgreSQL, MS SQL Server, Oracle)

3) Выгрузка заказов
ООО «Эффективные решения для интернет-бизнеса»
50+ установок
Бесплатно 7 дней, далее —1000₽ за месяц

Универсальный экспорт заказов для МоегоСклада.

Расширение предназначено для автоматизации выгрузки заказов покупателей из МоегоСклада во внешние системы, файлы и каналы связи. Оно позволяет гибко настраивать состав данных, расписание и способы доставки.

Основные возможности:

1. Поддерживаемые форматы:
- Excel (XLSX) - профессиональные таблицы с автоподбором ширины колонок и группировкой.
- CSV - универсальный текстовый формат для импорта в другие системы.
- JSON - для интеграции с веб-сервисами.
- XML - для интеграции с веб-сервисами.
- HTML - интерактивные отчеты с поиском, пагинацией и отображением изображений товаров.

2. Каналы доставки:
- Email (SMTP) - автоматическая отправка файлов на одну или несколько почт (поддержка SSL/TLS).
- Google Sheets - прямая выгрузка данных в ваши таблицы Google в реальном времени.
- Telegram - получение файлов и уведомлений через Telegram-бота.
- FTP/SFTP - загрузка отчетов на удаленные серверы.
- Webhooks - отправка данных по протоколу POST на любой URL.
- Базы данных - запись данных напрямую в MySQL или SQLite.

3. Гибкая фильтрация заказов:
- По организациям и складам.
- По статусам заказов (выбор одного или нескольких).
- По периоду: сегодня, вчера, текущая неделя/месяц или произвольный диапазон дат.
- По сумме заказа (минимальная и максимальная).


4. Настройка данных:
- Выбор из 30+ стандартных полей (номер, дата, сумма, покупатель, адрес, артикул, штрихкод, скидки и др.).
- Полная поддержка дополнительных полей (характеристик) заказов.
- Опция «Один заказ = одна строка» для создания кратких сводных отчетов.
- Специальные поля для региона Узбекистан (ИКПУ, коды упаковок, маркировка).

5. Автоматизация по расписанию:
- Ежедневно в указанное время.
- Интервальный запуск (каждые N часов).
- «Умный» режим (автоподбор интервала в зависимости от объема данных).

Преимущества:
- Простая установка и интуитивно понятный интерфейс управления.
- Стабильная работа с большими объемами данных.
- Возможность создания множества независимых конфигураций (профилей) экспорта.
- Контроль статуса выполнения задач в реальном времени.

Инструкция по началу работы:
1. Установите расширение в вашем аккаунте МойСклад.
2. Откройте приложение и создайте новую конфигурацию экспорта.
3. Выберите нужные фильтры, поля для выгрузки и способ доставки.
4. Проверьте настройки с помощью кнопки «Тест» и активируйте расписание, если требуется автоматизация.

Что выгружается?
На данный момент выгружаются следующие сущности (в момент создания или обновления):

Заказы покупателей (включая позиции);

Продажи (отгрузки и розничные продажи, включая позиции);

Платежи (входящие и исходящие платежи, приходные и кассовые ордера);

Заказы поставщикам (включая позиции);

Приемки (включая позиции);

Возвраты (включая позиции);

Списания и оприходования (включая позиции);

Полученные отчеты комиссионеров (включая позиции).

А также на периодической основе (на данный один раз в сутки):

Ассортимент (включая остатки и резервы по складам);

Контрагент (включая показатели контрагент, если подключена опция МойСклад CRM);

Возможные применения приложения:
Анализ движения денежных средств (отчет ДДС);

План/факт продаж.
